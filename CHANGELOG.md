## [0.1.0] - 2026-07-30

### Added

- Strict US/EU/global allergen declaration profiles and custom IDs.
- Guest × dish `BLOCK` / `HOLD` / `CANDIDATE` analysis with reason paths.
- Preparation and shared-service cross-contact tracing.
- Free-from contradiction and evidence-quality findings.
- Accessible HTML report, print cards, CSV, JSON, Markdown, receipt, and hashes.
- Deterministic portable ZIP plus bounded no-extraction verification.
- Passing and deliberately failing example cases.
- Zero-dependency zipapp, wheel, source archive, example bundle, and checksums.
- Linux/Windows CI, reproducibility gate, and automated GitHub Release workflow.
